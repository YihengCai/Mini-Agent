# 模型服务能力记录

项目只使用本地配置显式指定的端点与 wire adapter；仓库不预设模型服务。Anthropic-compatible 或 OpenAI-compatible 只描述消息格式，不能据此推断同名 vendor、兼容服务或任何扩展能力已经验证。

这份文档只记录实际运行过的能力探测，不预填未来功能可能需要的矩阵。某项当前实现确实依赖缓存、流式输出、推理块往返、`usage` 语义或上下文上限时，先写最小探测并征得运行真实 API 的同意，再新增记录。

在探测前，adapter 映射出的基础 `usage` 只作为观察数据，不参与压缩控制；自动压缩默认关闭。可选的 `local_compaction_token_limit` 只启用旧本地近似估算，不代表端点的 tokenizer 或上下文上限（`mini_agent/core/agent.py:107-111,136-140,239-326,678-681`）。

每条记录必须包含：

- 为什么当前实现依赖这项能力；
- 可重复运行的命令或脚本；
- 端点、模型、SDK 版本和日期；
- 原始错误码、响应字段或 `usage` 证据；
- 不支持或结论不明确时的降级方案。
