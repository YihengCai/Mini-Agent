# 模型服务能力记录

项目只使用本地配置显式指定的端点与 wire adapter；仓库不预设模型服务。Anthropic-compatible 或 OpenAI-compatible 只描述消息格式，不能据此推断同名 vendor、兼容服务或任何扩展能力已经验证。

这份文档只记录实际运行过的能力探测，不预填未来功能可能需要的矩阵。某项当前实现确实依赖缓存、流式输出、推理块往返、`usage` 语义或上下文上限时，先写最小探测并征得运行真实 API 的同意，再新增记录。

在探测前，adapter 映射出的基础 `usage` 只作为观察数据。当前没有自动上下文策略，也不假定配置端点的 tokenizer 或上下文上限；完整历史会直接进入每次模型请求（`mini_agent/core/agent.py:122-127,329-349,380-383`）。未来策略若依赖 vendor 能力，仍须先补本页探测并提供明确降级方案。

每条记录必须包含：

- 为什么当前实现依赖这项能力；
- 可重复运行的命令或脚本；
- 端点、模型、SDK 版本和日期；
- 原始错误码、响应字段或 `usage` 证据；
- 不支持或结论不明确时的降级方案。
