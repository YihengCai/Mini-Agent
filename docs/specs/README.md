# 实现前规格

这里只记录当前正在准备实现的模块，不枚举未来架构。规则：

1. 只写要解决的问题、不变量、边界和能够暴露当前缺陷的回归测试；代码是实现的事实来源。
2. 实现开始前才创建规格，完成后由代码、测试和 ADR 接管事实来源。
3. 中文是唯一文档语言；有成熟译法的词使用中文，没有稳定译法的专有概念才保留英文。

当前没有正在实施的规格。当前能力见 [`README.md`](../../README.md)，进度与待研究问题见 [`BUILD_LIST.md`](../BUILD_LIST.md)，已发生的取舍见 [`decisions/`](../decisions/README.md)。进入下一项实现时，再根据当时的代码、回归测试和端点探测结果创建短规格；完成后删除，不在这里维护第四份现状副本。
